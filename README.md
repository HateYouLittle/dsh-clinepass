# dsh-clinepass

[English](README.en.md)

为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 提供 **ClinePass 订阅的模型接入、用量查看与多账号管理**，让额度、重置时间和账号切换更方便。

本插件派生自 [dsh-opencode-go](https://github.com/Duskriver/dsh-opencode-go)，按 ClinePass 的接口重写了模型目录、用量读取与请求身份，其余设置界面与账号机制沿用同一套实现。

- **用量随手可查**：在会话输入区查看用量，展开查看 5 小时、每周、每月已用百分比与重置时间。
- **多个账号集中管理**：查看各账号 Key 状态，拖动排序，在会话中手动切换，也可开启自动使用备用账号。
- **模型与设置更直观**：搜索和筛选模型，调整显示、容量与思考预算；高级设置按用途分组，提供提示与恢复默认操作。
- **随插件发布的模型目录**：ClinePass 没有公开的模型能力文档，因此模型清单、协议、上下文与价格都随插件发布，不依赖任何在线目录。

支持中文和英文，跟随 DSH 的界面语言。

`cline-pass/*` 是订阅模型，`cline-free/*` 是 Cline 免费额度，两者使用同一个 API Key 与同一个接口地址，因此一并提供；免费模型名称带“（free）”，避免与同名付费模型混淆。

价格使用实测计费费率（$/1M tokens），用于设置页与用量分析中的估算，**不参与 ClinePass 额度计算**：订阅额度以官方百分比为准。

## 查看订阅用量

点击会话输入区旁的用量胶囊，展开当前账号的订阅用量。进度条显示**已用百分比**，接近上限时变为黄色，耗尽时变为红色；每个额度窗口都显示重置时间。

用量来自 Cline 的订阅接口 `GET /users/me/plan/usage-limits`，它按 `five_hour`、`weekly`、`monthly` 三个窗口返回已用百分比与重置时间。

显示用量时每分钟自动刷新；页面进入后台时暂停周期查询，回到前台后刷新。暂时查询失败时，面板会提示失败，并在可保留上次数据时标明“上次数据”，可点击“立即重试”。也可以在设置页的账号卡片中点击 **刷新额度**。

在 **设置 → ClinePass → 高级设置 → 额度显示** 中选择：

| 模式 | 行为 |
| --- | --- |
| 自动（默认） | 选中 **DSH ClinePass** 模型时显示 |
| 常驻 | 使用其他模型时也显示已配置的 ClinePass 账号用量 |
| 关闭 | 隐藏会话用量胶囊并停止其轮询 |

## 管理多个账号

在 **设置 → ClinePass → 账号** 中集中管理账号：

- 添加账号、重命名、替换 Key 或删除账号；最多支持 20 个账号。
- 每行查看 Key 状态、5 小时已用百分比和重置倒计时，展开查看完整用量与账号操作。
- 拖动行首手柄调整顺序，第一行成为当前账号；顺序也决定自动尝试备用账号的次序。
- 在会话用量面板中点击 **切换**，将所选账号移至首位，供本 profile 后续请求使用；其他账号的相对顺序保持不变。

开启 **自动使用备用账号** 后，当前账号额度耗尽或 Key 不可用时，插件会在开始输出前按顺序尝试其他账号。开始正常输出的备用账号会移至首位并成为当前账号，用量面板会显示切换提示。请求已经输出、产生 token 用量或被取消后，不会自动切换账号重发。

Key 通过 DSH 凭据服务保存，设置页不会回显已保存的密钥。

## 安装与快速开始

适用于 DSH `0.1.5-rc.1` 及以上版本，已在 `0.2.1-rc.3` 上验证。

### 在 DSH 中安装

在 **插件 → 添加插件** 中选择本仓库的目录，或使用命令行把当前目录作为安装目标：

```sh
dsh plugin --profile desktop add @crackedopal/dsh-clinepass
```

也可以直接使用 `plugin_manager` 的 `install_bundle`，把本仓库的绝对路径作为安装目标。

安装完成后点击 **立即启用**，然后启动或重启 `dsh web`（桌面版完全退出后重新打开）。

### 开始使用

1. 在 [app.cline.bot → Settings → API Keys](https://app.cline.bot/settings/api-keys) 创建一个 API Key。
2. 打开 **设置 → ClinePass**，填入 API Key 并保存，或在 **账号** 中添加账号。
3. 在会话模型选择器中选择 **DSH ClinePass** 下的模型。
4. 开始对话，在输入区旁查看用量；有多个账号时可展开面板切换。

插件使用独立的模型提供方 **DSH ClinePass**。选择 DSH 原生提供的模型不会自动使用本插件的账号切换功能；“常驻”模式仍可展示本插件已配置账号的用量。

## 模型与设置

### 选择模型与调整参数

在 **可用模型** 中按名称或 ID 搜索，也可以筛选 **已自定义** 或 **过时模型**。

- 模型开关控制它是否出现在会话选择器中，修改立即生效。
- 选中模型可查看随插件发布的上下文窗口、最大输出和输入模态，容量覆盖保存后生效，留空使用默认值。
- 支持思考的模型提供相应开关、强度或 token 预算选项；预算式模型还可添加自定义预算并保存。

`cline-pass/deepseek-v4.1-flash` 每次请求默认使用 **64k（65,536 tokens）** 的输出预算，模型输出上限更小时取较小值，并将该默认值告知 DSH 用于计算压缩时机。该规则只应用于此模型；其他模型沿用 SDK 的默认输出行为。需要更长回答时，可在模型容量覆盖中设置「最大输出」。

流式回复、思考、工具调用和图片输入取决于模型能力。只有模型目录声明了图像模态的模型接受图片附件，其余模型会在发出请求前拒绝图片内容。

### 分组高级设置

高级设置按 **用量**、**连接**、**缓存与超时**、**图片处理** 分组。悬停问号查看说明，可通过 **全部恢复默认** 清除该卡片的自定义覆盖，再保存修改；当前账号选择保持不变。

支持 HTTP、HTTPS 和 SOCKS5 代理，保存后用于后续对话与用量查询。代理运行在 DSH 所在的机器上；远程部署中的 `127.0.0.1` 指服务器自身。

ClinePass 只提供 OpenAI 兼容的 Chat Completions 协议，因此本插件不提供协议切换选项。

## 更新与常见问题

更新后重启 `dsh web` 并刷新页面；桌面版完全退出后重新打开。

**为什么没有显示用量？** 默认“自动”模式仅在选择 **DSH ClinePass** 模型时显示。请检查插件是否启用、Key 是否配置，以及额度显示模式；使用其他提供方时可选择“常驻”。

**Key 无效或额度用尽怎么办？** 用量接口返回 401/403 表示 Key 被拒绝，429 表示被限流；账号卡片会显示失败原因并可重试。若配置了多个账号并开启自动切换，插件会在开始输出前尝试下一个账号。

**某个模型不在列表里？** 模型清单随插件发布。Cline 的 `GET /models` 列表只包含通用路由目录，不含 `cline-pass/*` 订阅 ID；若该列表出现插件未收录的 `cline-pass/*` 或 `cline-free/*` 模型，设置页会把它标记为“缺少配置”，此时需要升级插件。

**长会话持续报 400 怎么办？** 检查错误中的输出预算与上下文窗口，可执行 `/compact` 或调低该模型的「最大输出」后重试。明确的上下文超限会交给 DSH 的恢复机制。

**升级后旧会话找不到模型？** 手动配置使用 `provider: dsh-clinepass`。

卸载：

```sh
dsh plugin --profile desktop remove @crackedopal/dsh-clinepass
```
